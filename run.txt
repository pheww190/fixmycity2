========================================================================
             FIXMYCITY - MUNICIPAL GRIEVANCE PLATFORM
========================================================================

Follow these steps to run the platform locally on your machine.

1. PREREQUISITES
----------------
Ensure you have the following installed:
- Node.js (v18 or higher)
- Python 3.x (Required for Analytics Charts)

2. INSTALLATION
---------------
Open your terminal in the project root directory and run:

A. Install Node.js Dependencies:
   > npm install
   > cd backend
   > npm install
   
B. Install Python Dependencies:
   > pip install matplotlib numpy

3. STARTING THE PLATFORM
------------------------
From the /backend directory, run:
   > npm start

The server will start at: http://localhost:3000

4. PROJECT ACCESS
-----------------
- Citizen Portal:   http://localhost:3000/citizen/login
- Admin Dashboard:  http://localhost:3000/admin/login
- Public Map:       http://localhost:3000/public-map.html (Accessible via Home)

6. DATABASE (Offline & Portable)
--------------------------------
The project uses a local SQLite database located at:
/backend/data/database.sqlite

This makes the project 100% portable. You can zip the folder and share it, 
and the next person will have all your data and can run it immediately!

7. KEY FEATURES
---------------
- AI-Powered Complaint Classification (Keyword-based)
- Auto-Geotagging (Extracts GPS from photos)
- Nearby Duplicate Detection (Prevents redundant reports)
- Analytics Dashboard (Python-generated charts)
- Community Support System (Upvote existing complaints)
